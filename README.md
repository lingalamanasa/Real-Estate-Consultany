### 🚀 Key Features
- **Public Website Pages**:
  - `index.html` - Comprehensive homepage with hero telemetry, market stats, interactive mortgage & ROI calculators, project showcases, and consultation booking.
  - `about.html` - Vision, RICS-accredited leadership team, advisory practice benchmarks, and client testimonials.
  - `services.html` - Institutional acquisitions, title diagnostic lab, commercial leasing, and NRI cross-border desk.
  - `blog.html` - RERA legal updates, 2026 market intelligence, and investment whitepapers.
  - `contact.html` - Salem headquarters contact desk, priority callback booking, and interactive FAQ accordions.
- **Client & Admin Cockpits**:
  - `admin-dashboard.html` - Executive Cockpit with live telemetry, token queues, forensic risk scoring, and fee realization.
  - `user-dashboard.html` - Investor property portfolio dashboard, active consultations, milestone tracking, and vault access.
- **Authentication**:
  - `login.html` & `signup.html` - Dynamic role-based authentication (Investor / Admin) with automated user profile state management.
- **404 Error Experience**:
  - `404.html` - Interactive error page with animated canvas, quick return routes, and preserved navigation.
